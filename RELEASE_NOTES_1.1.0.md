# Notch Plus 1.1.0 — громкость внутри Dynamic Island

[Скачать Notch Plus 1.1.0 для Apple Silicon](https://github.com/Torus211/notch-plus/releases/download/v1.1.0/NotchPlus-1.1.0-arm64.zip)

Для **Mac с Apple Silicon и macOS 15.5 или новее**. Intel-версия в этот релиз не входит.

## Что изменилось

- Регулятор громкости теперь внутри Dynamic Island: плавная шкала, проценты и перетаскивание мышью.
- Индикатор остаётся видимым во время перетаскивания; добавлена регулировка через VoiceOver.
- Исправлена проверка разрешения для перехвата медиаклавиш. Настройка замены системного HUD больше не сбрасывается при временной потере доступа.
- Перехват восстанавливается после временного отключения macOS; исправлена обработка событий клавиш.
- Добавлены страница настройки при первом запуске без доступа, переход в системные настройки, предпросмотр и статус работы перехвата.
- Включено исправление запуска без иконки Dock, в том числе при открытых настройках.
- Компоненты питомца в эту сборку не входят. Шесть вкладок: Музыка, Полка, Календарь, Буфер, Фокус и Заметки.

## Установка и первый запуск

1. Закройте Notch Plus и другие приложения для выреза. Распакуйте ZIP и перенесите **Notch Plus.app** в **Программы**.
2. Запустите приложение из «Программ». Сборка **подписана локально, без нотариального заверения Apple**. macOS может заблокировать первый запуск. Если доверяете загрузке, используйте разрешение запуска в **Системные настройки → Конфиденциальность и безопасность**.
3. Для громкости и яркости внутри острова включите **Notch Plus** в **Конфиденциальность и безопасность → Универсальный доступ**. На новых macOS раздел называется **Device Control and Data Access**. Подтверждение через Touch ID или пароль выполняет сам пользователь.
4. Перезапустите приложение. В **Settings → HUDs** должны быть включены **Replace system HUD** и стиль **Inside Dynamic Island**. Статус: **Keyboard volume control is active in Dynamic Island.**

Разрешение macOS нельзя включить заранее в архиве. Пока его нет, кнопки громкости работают обычным способом через macOS. Календарь и напоминания запрашивают отдельные разрешения.

## Если обновляетесь

Заменяйте приложение, когда оно закрыто. Заметки и история буфера сохраняются в прежнем контейнере.

Если системный переключатель разрешения включён, но приложение не видит доступ: удалите старую запись Notch Plus кнопкой **−**, добавьте **/Applications/Notch Plus.app** кнопкой **+**, включите доступ и перезапустите приложение. Это понадобилось при локальном обновлении подписи сборки.

Автоматические обновления отключены. Следующие версии скачиваются из GitHub Releases вручную.

## Что проверено

Release-сборка arm64, локальная подпись, 15 проверок ядра, целостность архива и контрольная сумма. В работающем приложении проверены предпросмотр громкости и успешный запуск перехвата после обновления системного разрешения. Физическое нажатие медиаклавиш инструментом автоматизации не воспроизводилось. Чистая установка на другом Mac, все версии macOS, календарные разрешения, AirDrop и камера отдельно не проверены.
