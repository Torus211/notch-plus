# Notch Plus for macOS

A personal fork of [TheBoredTeam/boring.notch](https://github.com/TheBoredTeam/boring.notch), based on v2.7.3.
Native SwiftUI notch app with six tabs: Music, Shelf, Calendar, Clipboard, Weather and Devices.

- Keeps the original music player, file shelf/AirDrop, gestures, battery UI and settings.
- Moves the existing calendar/events/reminders into a dedicated tab.
- Adds local clipboard history with search, pins, pause and deletion.
- Adds weather with city search (Krasnodar by default), powered by Open-Meteo.
- Shows paired Bluetooth devices and connection changes inside the island.
- Keeps clipboard history in its own dedicated tab.
- Removes Focus, Notes, the experimental feature hub and lock-screen cards.
- Shows a smooth, draggable volume control with a percentage inside Dynamic Island.
- Applies the selected accent immediately across the island, tabs, clipboard and settings.
- Runs without a Dock icon, including while settings are open.
- Bounds clipboard payloads and thumbnail caching, coalesces background writes,
  and stops player/lyrics timeline updates while playback is paused.

## Install

Download **[Notch Plus 1.2.0 for Apple Silicon](https://github.com/Torus211/notch-plus/releases/download/v1.2.0/NotchPlus-1.2.0-arm64.zip)**
or visit **[the latest release](https://github.com/Torus211/notch-plus/releases/latest)**.
The packaged app and helper require **macOS 15.5 or later** and an **Apple Silicon Mac**.
Intel Macs are not supported by this archive.

1. Quit Notch Plus and other notch apps. Unzip and move **Notch Plus.app** to **Applications**.
2. Launch it from Applications. This build is ad-hoc signed and **not notarized by Apple**;
   macOS may block its first launch. Only if you trust this download, use the approval
   offered in **System Settings → Privacy & Security**.
3. To replace the system volume/brightness indicator, allow **Notch Plus** in
   **System Settings → Privacy & Security → Accessibility** (called **Device Control
   and Data Access** on newer macOS). macOS may ask for Touch ID or your Mac password.
   The app opens its HUD setup page once when this access is missing.
4. Quit and reopen Notch Plus. In **Settings → HUDs**, keep **Replace system HUD** on
   and choose **Inside Dynamic Island**. The status should read
   **Keyboard volume control is active in Dynamic Island.**

Volume now uses a smooth bar and percentage inside the island, with mouse dragging.
Without the required system permission, volume keys continue to work through macOS.
Calendar/reminder access is requested separately. Permissions cannot be bundled with a download.

### Updating from an older build

Replace the app in Applications while it is closed; notes and clipboard history are
kept in the existing app container. If permission is shown as enabled in macOS but
Notch Plus still reports no access, remove its old permission entry with **−**, add
**/Applications/Notch Plus.app** with **+**, enable it, then quit and reopen the app.
This was necessary locally after rebuilding the ad-hoc signed app. A working switch
in System Settings alone does not prove the current running build has access.
Automatic updates are disabled; download future releases manually.

## Build

On an Apple Silicon Mac with Xcode installed:

```sh
zsh tools/build.sh
```

Output: `dist/Notch Plus.app`. The script preserves a previous build before replacing it.
The app has its own identifier (`local.torus.notchplus`), and official Boring Notch
updates are disabled so they cannot replace this fork.

## Verify

```sh
swiftc boringNotch/NotchPlusCore.swift Tests/CoreChecks.swift -o /tmp/notchplus-checks
/tmp/notchplus-checks
```

15 logic checks cover timer start/pause/resume/completion after sleep, restart state,
history bounds, pinned eviction and serialization. See [Russian notes](NOTCH_PLUS.md)
for details, limitations and local verification results.

## Privacy and limits

History starts with the current system clipboard item. Older Raycast history is not
imported. Supports text/links, the first file in a copied set, and small images.
Limits: 120 records, 16 MiB of payloads, 2 MiB per item, 64 KiB per text item,
4 million pixels per image. Pins are subject to the same hard limits.

Clipboard history is stored locally in the app sandbox. Weather uses Open-Meteo. Entries marked concealed/transient/autogenerated are skipped;
this depends on the copying application marking sensitive items correctly.
Local files are not separately encrypted. Original media features may use the network.
No personal clipboard history, notes or user preference exports are included here.

## Weather and devices

Weather sends the selected city coordinates to [Open-Meteo](https://open-meteo.com/); city search sends the search text to its geocoding service. No GPS is used. Bluetooth uses macOS paired-device information without a discovery scan; enable connection activity in Devices. The app does not display content on the lock screen. Focus and Notes are no longer exposed; existing local note files are retained.
