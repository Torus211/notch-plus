# Notch Plus for macOS

A personal fork of [TheBoredTeam/boring.notch](https://github.com/TheBoredTeam/boring.notch), based on v2.7.3.
Native SwiftUI notch app with six tabs: Music, Shelf, Calendar, Clipboard, Focus and Notes.

- Keeps the original music player, file shelf/AirDrop, gestures, battery UI and settings.
- Moves the existing calendar/events/reminders into a dedicated tab.
- Adds local clipboard history with search, pins, pause and deletion.
- Adds a focus/break timer and an autosaving quick note.
- Bounds clipboard payloads and thumbnail caching, coalesces background writes,
  and stops player/lyrics timeline updates while playback is paused.

## Install

Download the Apple Silicon archive from **Releases**, unzip it, move **Notch Plus.app**
to Applications, and launch. This is an ad-hoc signed local build, not notarized by Apple.
Only run one notch application at a time. macOS may ask for calendar/reminder access.

## Build

On an Apple Silicon Mac with Xcode installed:

```sh
zsh tools/build.sh
```

Output: `dist/Notch Plus.app`. The script preserves a previous build before replacing it.
The app has its own identifier (`local.torus.notchplus`), and official Boring Notch
updates are disabled so they cannot replace this fork.

## Verify

```sh
swiftc boringNotch/NotchPlusCore.swift Tests/CoreChecks.swift -o /tmp/notchplus-checks
/tmp/notchplus-checks
```

15 logic checks cover timer start/pause/resume/completion after sleep, restart state,
history bounds, pinned eviction and serialization. See [Russian notes](NOTCH_PLUS.md)
for details, limitations and local verification results.

## Privacy and limits

History starts with the current system clipboard item. Older Raycast history is not
imported. Supports text/links, the first file in a copied set, and small images.
Limits: 120 records, 16 MiB of payloads, 2 MiB per item, 64 KiB per text item,
4 million pixels per image. Pins are subject to the same hard limits.

History and notes are stored locally in the app sandbox. The new tabs do not use
network services. Entries marked concealed/transient/autogenerated are skipped;
this depends on the copying application marking sensitive items correctly.
Local files are not separately encrypted. Original media features may use the network.
No personal clipboard history, notes or user preference exports are included here.
